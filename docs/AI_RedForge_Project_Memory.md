## 1. What we are building

AI-RedForge = **Agentic AI Red-Team Factory**: a multi-agent swarm that runs bounded, auditable attack
campaigns against deployed LLM apps/copilots/agents (OWASP LLM Top 10 2025 + Agentic Top 10 2026 +
MITRE ATLAS), judges findings in dual mode (rule detectors → LLM-as-judge → human for criticals),
and ships an audit-grade regulatory dossier (EU AI Act Art 15 / ISO 42001 / NIST AI RMF).

Blueprint entities: 6 architecture layers, 10 target classes, 40 techniques (PIN 10, EXF 7, OUT 4,
AGE 7, MEM 3, CON 4, HAL 3, SUP 2), 6-dimension scorecard (weights .25/.20/.20/.15/.10/.10),
phases A0–A6, 9 runtime pipeline agents + G1/G2 gates (11 swarm nodes; 14 fixture schematic nodes in ops HUD only), 6 MCP servers
(6 P0), 36 tasks / 12 weeks, 14 KPIs, 10 risks.

### API quirks discovered (DO NOT re-learn these)
1. **PyRIT 1.x new layout**: orchestrators are now `pyrit.executor` (attack/benchmark/promptgen/workflow),
   scoring `pyrit.score.llm_scoring`, memory `pyrit.memory.sqlite_memory`. Old 0.x `pyrit.orchestrator` is GONE.
   mcp-pyrit adapter targets the 1.x API.
2. **MCP SDK 2.x rename**: official `from mcp.server.fastmcp import FastMCP` is GONE → use
   `from mcp.server.mcpserver import MCPServer` OR standalone `from fastmcp import FastMCP` (both installed, both verified).
3. **Git Bash path mangling**: `.cmd` shims (promptfoo) and downloaded exes fail when invoked directly.
   Workarounds: promptfoo via `node "$APPDATA/npm/node_modules/promptfoo/dist/src/entrypoint.js"`;
   OPA via `cmd //c` or subprocess arg-list (production adapters use subprocess lists — no issue).
4. fastapi was upgraded 0.111→0.141.1 to fix starlette conflict introduced by MCP SDK (resolved).

- **Q-11**: Next.js 15 rewrites BUFFER SSE bodies for browsers (curl sees data, EventSource sees headers only) →
  console EventSource targets the API origin directly (`NEXT_PUBLIC_API_BASE`, default http://127.0.0.1:8000);
  API CORS now allowlists :3000 and :3100. SSE replay-on-connect is a feature (late joiners get history).
- **Q-12 (FIXED, two parts)**: `LiveCampaign.start()` called `self.__init__()` which (a) wiped `self.queues` and
  (b) reset seq numbering to 1 — while the stream generator gates delivery on `e.seq > sent`, so any subscriber
  that had replayed history silently discarded ALL new-campaign events. Fixed by preserving subscribers AND the
  monotonic seq counter across the reset; airtight regression test
  `test_sse_subscriber_survives_campaign_restart` (anchors on pre-connect max seq). Old M6c e2e `text=JUDGE`
  assertion had matched the DAG label, masking this for sessions — now asserts real stream text
  ('payload dispatched'). Console also batches SSE events at 4Hz (replay + burst re-render pressure).

## 6. Agentic UI plan — "RedForge Console" (added session 3, D5)

**Philosophy**: the Console is the window into an autonomous red-team swarm — every agent action
visible, every artifact traceable, every human gate actionable; audit-grade by construction
(everything rendered from the evidence store); dual aesthetic: dark ops-room for operators,
clean light views for client execs.

**Personas**: Red Operator · Engagement Lead/CISO · Compliance officer · Exec sponsor · Admin.

**Screens (10)**:
1. Command Center — active campaigns, swarm health, budget burn, KPI tiles
2. **Mission Control (flagship)** — live 9-agent + G1/G2 DAG (React Flow), streaming transcript feed,
   round tracker (R1–R3), budget meters, kill-switch, agent-trace replay
3. Findings Explorer — filters (pack/technique/severity/target), evidence drawer
   (transcript + dual-mode verdict breakdown + confidence), FP-void workflow, kill-chain graph
4. AI Security Scorecard — live 6-dim radar, weight sliders (mirrors workbook calculator), trend lines
5. Regulatory Dossier — Art 15 / ISO 42001 / NIST mapping matrix, evidence-linked, PDF export
6. Gatekeeper Console — approval inbox, two-person rule UI, ROAI scope check, approvals log
7. Target Registry — 10 classes, health, surface maps, canary status
8. Technique Library — 40 techniques, payload corpus manager, mutation lineage visualizer
9. Sentinel / Continuous — regression timeline, update detections, drift scorecard, CI-gate widget
10. Admin & Governance — RBAC/SSO, audit-trail viewer, MCP server status board, budget caps

**Console Copilot** (differentiator): chat pane backed by the same MCP tool servers —
"ask the swarm" natural-language queries over findings/evidence; demonstrates MCP-first API.

**Stack**: Next.js App Router + TypeScript + Tailwind + shadcn/ui; SSE streaming (FastAPI event bus:
agent_state_change, transcript_delta, verdict, budget_tick, gate_request, finding_created);
React Flow (DAG) + Recharts; event-sourced state replay (pattern from threat-modeller GUI);
virtualized transcripts. **Enterprise**: RBAC 5 roles, OIDC/SAML SSO, multi-tenant client
workspaces, white-label client views, full view/export audit trail, WCAG 2.1 AA, i18n-ready,
API-first (UI = just another client of the same REST/MCP surface).
